# Kenney City Kit Commercial

Selected FBX models from Kenney's City Kit Commercial 2.1 create a generic urban skyline along the BRT route.

Source: https://kenney.nl/assets/city-kit-commercial
License: Creative Commons Zero (CC0), included in `License.txt`. Attribution is optional; Kenney is credited here.

The models are loaded from `Resources/KenneyCityCommercial` at runtime. The buildings are generic placeholders, not a depiction of a specific Mashhad location.
