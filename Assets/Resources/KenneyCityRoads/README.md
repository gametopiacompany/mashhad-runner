# Kenney City Kit (Roads)

Selected low-poly FBX models from Kenney's City Kit (Roads) 2.2:

- `light-square` and `traffic-light` for roadside detail
- `construction-barrier` for gameplay obstacles

Source: https://kenney.nl/assets/city-kit-roads
License: Creative Commons Zero (CC0), included in `License.txt`. Attribution is optional; Kenney is credited here.

The props are loaded from `Resources/KenneyCityRoads` at runtime. The BRT route uses a continuous primitive asphalt surface so the kit's city-grid markings do not repeat across the runner's view.
