# Kenney Mini Characters

Selected low-poly FBX characters from Kenney's Mini Characters 2.0:

- `character-male-a` for the runner
- `character-worker` for the pursuing agent

Source: https://kenney.nl/assets/mini-characters
License: Creative Commons Zero (CC0), included in `License.txt`. Attribution is optional; Kenney is credited here.

The models are loaded from `Resources/KenneyMiniCharacters` at runtime. The runner's squash and sway motions are prototype animation only.
